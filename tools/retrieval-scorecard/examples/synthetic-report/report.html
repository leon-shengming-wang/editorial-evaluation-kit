How to read these scores

Query universeAll qrels queries count equally. Missing runs score zero; extra run queries are excluded.
Unjudged documentsRetained at their original rank with zero gain. Unknown labels stay distinguishable from explicit zero judgments.
Binary relevance and precisionAny grade above zero is relevant. Precision always divides by k, even for a short run.
Graded rankingDCG uses grade / log2(rank + 1). Ideal DCG uses all judgments in descending grade order.
Zero-relevance conventionRecall and nDCG are set to zero when their denominator is zero. These queries remain in the macro mean.
Display precisionScores are rounded to four decimals here. JSON retains numeric precision. nDCG uses max-grade-scaled gains to avoid tiny-number underflow; raw DCG can underflow.
